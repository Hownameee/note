# BeanDefinition Cheat Sheet

A `BeanDefinition` is the internal representation of a Spring Bean. It is the metadata that Spring uses to understand how to instantiate, configure, and assemble a bean.

---

## 1. Class
*   **What it is:** The fully qualified class name of the bean. This tells Spring exactly which class to instantiate using reflection.
*   **Default:** None (Mandatory for standard beans).
*   **Use Case:** Every standard bean needs a class so Spring knows what object to create.
*   **Demo:**
    ```java
    // Annotation
    @Component
    public class UserService {}
    
    // Java Config
    @Bean
    public UserService userService() {
        return new UserService();
    }
    ```

---

## 2. Name
*   **What it is:** The unique identifier (and aliases) for the bean in the container.
*   **Default:** The camelCase version of the class name (e.g., `UserService` becomes `userService`). For `@Bean` methods, it defaults to the method name.
*   **Use Case:** To fetch a specific bean from the context (`context.getBean("primaryUserService")`) or to disambiguate when autowiring multiple beans of the same type using `@Qualifier`.
*   **Demo:**
    ```java
    @Component("primaryUserService")
    public class UserService {}
    
    @Bean(name = {"dataSource", "primaryDataSource"})
    public DataSource dataSource() { 
        return new HikariDataSource(); 
    }
    ```

---

## 3. Scope
*   **What it is:** Defines the lifecycle and visibility of a bean instance.
*   **Default:** `singleton`
*   **Common Scopes:**
    *   `singleton`: One shared instance per Spring IoC container.
    *   `prototype`: A new instance is created every time the bean is requested.
*   **Use Case:** Use `singleton` for stateless services (like a DAO or utility class). Use `prototype` for stateful, non-thread-safe objects that need to be created freshly every time.
*   **Demo:**
    ```java
    @Component
    @Scope("prototype")
    public class ShoppingCart { 
        // Holds state specific to one user's session/interaction
    }
    ```

---

## 4. Constructor Arguments
*   **What it is:** Dependencies injected via the bean's constructor.
*   **Default:** Empty (uses a no-args constructor if available).
*   **Use Case:** **Mandatory dependencies.** If a `UserService` absolutely requires a `UserRepository` to function, it should be provided via a constructor argument. This ensures the object is never in an invalid state.
*   **Demo:**
    ```java
    @Service
    public class UserService {
        private final UserRepository repository;
        
        // Constructor Injection (Spring automatically injects this)
        public UserService(UserRepository repository) {
            this.repository = repository;
        }
    }
    ```

---

## 5. Properties
*   **What it is:** Dependencies or configuration values injected via setter methods or directly into fields.
*   **Default:** Empty.
*   **Use Case:** **Optional dependencies**, or configuring simple values (like database URLs or connection limits).
*   **Demo:**
    ```java
    @Service
    public class EmailService {
        @Value("${smtp.server}")
        private String smtpServer; // Field/Property injection
    
        private NotificationService notificationService;
    
        @Autowired
        public void setNotificationService(NotificationService notificationService) {
            this.notificationService = notificationService; // Setter injection
        }
    }
    ```

---

## 6. Autowiring Mode
*   **What it is:** How Spring automatically resolves dependencies for this bean.
*   **Default:** `no` (Modern Spring relies on annotation-driven injection like `@Autowired` which bypasses this XML-era setting).
*   **Modes:** `no`, `byName`, `byType`, `constructor`.
*   **Use Case:** Mostly relevant for legacy XML configurations where you want Spring to wire dependencies automatically without explicit `<property>` tags.

---

## 7. Lazy Initialization Mode
*   **What it is:** Determines *when* the bean is instantiated. 
*   **Default:** `false` (Eager initialization). Singleton beans are created immediately when the application context starts.
*   **Use Case:** Set to `true` (`@Lazy`) to delay instantiation until the bean is first requested. This is useful for heavy, resource-intensive beans that are rarely used, speeding up application startup time.
*   **Demo:**
    ```java
    @Component
    @Lazy
    public class HeavyReportGenerator {
        public HeavyReportGenerator() {
            System.out.println("This is only printed when first accessed!");
        }
    }
    ```

---

## 8. Initialization Method
*   **What it is:** A custom method called by the container immediately *after* all dependencies and properties have been injected.
*   **Default:** None.
*   **Use Case:** Performing validation, starting a background thread, opening a file, or verifying that all required configuration properties were correctly set.
*   **Demo:**
    ```java
    @Component
    public class CacheManager {
        
        @PostConstruct // Standard JSR-250 annotation
        public void init() {
            System.out.println("Cache initialized after dependencies injected.");
        }
    }
    ```
    ```java
    // Java Config Alternative
    @Bean(initMethod = "startCache")
    public CacheManager cacheManager() { ... }
    ```

---

## 9. Destruction Method
*   **What it is:** A custom method called by the container right before the bean is destroyed (typically during application shutdown). *Note: Spring does not manage the complete lifecycle of `prototype` beans, so destruction methods are not called for them.*
*   **Default:** None (Though Spring intelligently attempts to infer methods named `close()` or `shutdown()`).
*   **Use Case:** Releasing resources safely: closing database connection pools, shutting down thread pools, or flushing memory buffers.
*   **Demo:**
    ```java
    @Component
    public class ConnectionPool {
        
        @PreDestroy // Standard JSR-250 annotation
        public void cleanup() {
            System.out.println("Closing database connections before shutdown...");
        }
    }
    ```
    ```java
    // Java Config Alternative
    @Bean(destroyMethod = "close")
    public DataSource dataSource() { ... }
    ```
